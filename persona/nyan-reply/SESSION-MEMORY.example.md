# 对话记忆模板

每个对话一本，文件名就是会话 id（环境变量 `DSH_SESSION_ID` 的值），放在
`~/.dsh/roles/nyan-reply/sessions/<会话id>.md`。

**不进公开仓库**（里面是这次对话的私事）。

```md
# 对话记忆 · <会话id>

## 这次在做什么

- 

## 进展

- 

## 卡点 / 待办

- 

## 约定

- 

## 已归档

- 
```

## 和通用记忆的分工

| | 通用记忆 `MEMORY.md` | 对话记忆 `sessions/<id>.md` |
| --- | --- | --- |
| 内容 | 偏好、作息、忌讳、长期项目、人、亲密度 | 这次的任务、进度、卡点、临时约定 |
| 寿命 | 永久 | 随对话，结束时提炼归档 |
| 写错代价 | 大（会影响所有对话） | 小（改就完了） |

拿不准先写对话记忆，等它跨了几轮还在，再提炼上去。
